# Calculator

A simple web-based calculator. Pure HTML, CSS, and JavaScript — no build step, no dependencies.

## Usage

Open [index.html](index.html) in a browser.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Chained calculations (e.g. `5 + 3 * 2`)
- Decimal input, backspace, and clear
- Keyboard support: digits, `+ - * /`, `Enter`/`=`, `Backspace`, `Escape`
- Division by zero shows an error instead of crashing

## Files

- [index.html](index.html) — page structure and button layout
- [style.css](style.css) — styling
- [script.js](script.js) — calculator logic
